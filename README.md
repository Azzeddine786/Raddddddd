# راديو المغرب: النسخة النهائية

## ما الموجود
- `site/` : الموقع الجاهز للرفع (14 صفحة): الرئيسية، مركز المقالات، 5 مقالات، 6 صفحات ثقة، 404، sitemap.xml، robots.txt.
- `content/` : نصوص المقالات والصفحات و`stations.json` (48 محطة). عدّل هنا ثم أعد البناء.
- `assets/` : CSS وJS والأيقونة (`app-icon.png`) وصورة المشاركة.
- `build.py` : يولّد `site/` من `content/` (بايثون فقط، بدون تثبيت أي مكتبة).
- `docs/` : الهيكلة والسيو التقني واستراتيجية 3 أشهر.

## قبل الرفع (3 أشياء إلزامية)
1. **بريدك الحقيقي** (يظهر في الخصوصية واتصل بنا)، وتمرّره في `--email`.
2. **رابط موقعك النهائي** (يدخل في canonical وsitemap وOG).
3. **أيقونة التطبيق الحقيقية**: استبدل `assets/app-icon.png` (512×512) بأيقونة تطبيقك من Google Play، ثم أعد البناء. الموجودة الآن أيقونة بديلة صنعتها لأنني لا أصل إلى المتجر. وأعدّل `assets/app-icon-96.png` بنفس الأيقونة مصغّرة، وكذلك `icon-192.png` و`apple-touch-icon.png`.

## البناء
```bash
# رابط GitHub Pages كالحالي
python3 build.py --email you@example.com

# دومين مخصص (الأفضل لـ AdSense)
python3 build.py --url https://radiomaroc.ma --base "" --email contact@radiomaroc.ma

# بعد قبول AdSense فقط (يضيف سكربت AdSense وملف ads.txt)
python3 build.py --url https://radiomaroc.ma --base "" --email contact@radiomaroc.ma --adsense ca-pub-XXXXXXXXXXXXXXXX
```
ثم ارفع **محتويات** مجلد `site/` إلى المستودع أو الاستضافة.
