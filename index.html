ÉDITORIAL ORIGINAL

La radio marocaine, une voix du quotidien

Au Maroc, la radio accompagne les trajets du matin, les souks, les cafés, les ateliers et les longues routes entre les régions. Les stations nationales portent l’information et le service public, les radios musicales révèlent chaque saison de nouveaux artistes, tandis que les antennes régionales donnent la parole aux dialectes, aux traditions et à l’actualité locale. Radio Maroc a été conçu comme un annuaire éditorial — pas comme une simple liste de flux : chaque fiche doit expliquer qui parle, à qui, dans quelle langue et avec quel type de programmes, afin d’aider l’auditeur à choisir en confiance.

Thème Blogger XML — Radio Maroc 2026

Template valide avec b:skin, b:section, b:widget, widget Blog principal, labels, recherche, pagination, pages statiques, lecteur HLS et zones AdSense étiquetées. Copiez-le ou téléchargez le fichier .xml puis importez-le via Blogger → Thème → Restaurer.

APERÇU DU TEMPLATE (INTÉGRAL VIA COPIE / TÉLÉCHARGEMENT)

        
Installation Blogger
  1. Créez votre blog sur blogger.com puis reliez votre domaine personnalisé dans Paramètres → Publier.
  2. Téléchargez le XML ci-contre, allez dans Thème → Personnaliser (flèche) → Restaurer et importez le fichier.
  3. Dans Mise en page, vérifiez les sections : Header, Navigation, Ad-Header, Main (Blog1), Sidebar, Footer.
  4. Créez les pages statiques : À propos, Contact, Confidentialité, Conditions, Disclaimer, Copyright (textes fournis dans cette démo, boutons ci-dessus).
  5. Activez HTTPS, ajoutez la description du blog et le favicon, puis testez sur mobile.
Domaine : ajoutez les DNS fournis par Blogger (2 CNAME + A records), attendez la propagation, activez “Rediriger le domaine nu” et forcez HTTPS.

        
Ajouter une radio (1 article = 1 station)
  1. Nouvel article Blogger avec un titre unique : ex. “Hit Radio Maroc – Écouter en Direct”.
  2. Rédigez 400–700 mots originaux : présentation, histoire vérifiée, programmes, langues, public, site officiel.
  3. Ajoutez le lecteur avec : <button class="rm-play" data-stream="URL_OFFICIELLE" data-name="Nom">▶ Écouter</button>
  4. Ajoutez un seul label de catégorie (Musicales, Nationales…) + la ville en label secondaire si pertinent.
  5. Logo : uniquement officiel et autorisé. Sinon, utilisez une vignette éditoriale libre de droits avec alt descriptif.
Flux : utilisez uniquement une URL MP3/AAC/HLS fournie publiquement par la station ou licenciée pour intégration. Ne contournez jamais DRM, géoblocage ou authentification. Testez, documentez la source, retirez en cas de demande.

        
AdSense (après approbation uniquement)
  • Dans Mise en page, ouvrez chaque widget HTML “ADSENSE-…” et collez votre code (data-ad-client / slot réels). Ne modifiez jamais les clics.
  • Gardez l’étiquette “Publicité”, une distance avec le lecteur et les boutons Play, aucun format déguisé en navigation.
  • SEO : titres uniques, méta description par article, canonical automatique Blogger, images lazy-load, sitemap natif /sitemap.xml, robots.txt natif, Search Console + envoi du sitemap.
  • Publiez d’abord 15–25 fiches/articles substantiels et les 6 pages légales avant de postuler. Aucune garantie d’acceptation n’est promise.
